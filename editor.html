大切なお知らせ
この画面への入力だけでは公開サイトは変わりません。「index.html を保存」→ GitHubにアップロードして更新が完了します。GitHubにログインしていない人は、図鑑そのものを書き換えられません。

図鑑を読み込み中

公開中の図鑑を自動で読み込みます。最初は0作品から登録できます。

読み込めない場合は、前に保存した index.html を選ぶこともできます。

新しいお菓子を登録

公開済み図鑑を読み込んでいます。

登録予定の作品 0品

ここには登録した作品が並びます。0作品から始められます。追加・編集・削除した内容は、更新用ファイルをGitHubに反映するまで公開サイトには表示されません。

更新ファイルを保存

作品の追加・修正が終わったら押してください。画像もまとめた index.html がダウンロードされます。

読み込み完了後に使えるようになります。

③ GitHubに反映する方法

  1. GitHubのリポジトリ soumu-sweets-gallery を開く。
  2. Add file → Upload files を選ぶ。見えなければスマホのブラウザで「PC版サイト」を表示。
  3. ダウンロードした index.html をアップロード。同じ名前のファイルを上書きする。
  4. Commit changes を押し、公開中の図鑑を再読み込みして確認する。
注意：すでに index.html を保存済みだと、スマホが index (1).html のように改名する場合があります。その場合は、ファイル管理アプリで必ず index.html に名前を直してからGitHubへアップロードしてください。
更新するファイルは index.html だけです。editor.html は再アップロード不要です。
